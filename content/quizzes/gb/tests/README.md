# GB Mock Theory Test Sets (`set-01.json` – `set-10.json`)

Each file in this directory is a 50-question multiple-choice mock theory test built from `content/quizzes/gb/bank/`.

## Official Format Rules (GOV.UK Car Theory Test)
- **Questions:** 50 per test
- **Pass Mark:** **43 / 50** (86%)
- **Time Limit:** **57 minutes**
- **Difficulty Mix:** 40% easy (`difficulty: 1`, 20 questions), 40% medium (`difficulty: 2`, 20 questions), 20% hard (`difficulty: 3`, 10 questions)
- **Topic Balance:** No single rule exceeds 15% (<= 7 questions) in any set
- **Uniqueness:** No question repeats inside a set, and every question appears in at most 3 of the 10 sets
