# L to Local — *Keep Left*

A mobile (Android + iOS) driving game that teaches UK road rules by doing: drive realistic situations in a low-poly 3D world and get instant, explained feedback linked to the Highway Code.

**Status:** Phase 0 (planning). No game code yet.

- Start here: [docs/00-executive-summary.md](docs/00-executive-summary.md)
- Original brief: [uk-driving-sim-PROMPT.md](uk-driving-sim-PROMPT.md)

Educational practice tool only. It does not replace lessons with an approved driving instructor or the official tests, and it is not affiliated with DVSA or DfT.
