# Complex UK Roundabouts Research (4-, 5-, and 6-Exit)

**Verified from OpenStreetMap:** `west-midlands-latest.osm.pbf` (2026-11-26 Geofabrik extract, ODbL © OpenStreetMap contributors).  
**Highway Code rules:** Rules 184–190 (`https://www.gov.uk/guidance/the-highway-code/using-the-road-159-to-203`).

This pack documents real UK 4-, 5-, and 6-exit roundabouts (with OSM way IDs, coordinates, circulatory lane counts, signalisation, and road-arm descriptions) to guide the owner's backlog item on complex multi-exit roundabouts.

## 4. Recommended First Build Order & New Simulator Features Needed

### Recommended build sequence
1. **4-exit:** Queslett / Aldridge Road (`way=792`, unsignalised, 2 lanes) — validates 4-exit indexing with minimal rule changes.
2. **5-exit:** Six Ways Erdington (`way=759`, unsignalised, 2 lanes) — introduces 5-exit lane mapping before signals.
3. **6-exit:** Golden Hillock / Waverley Road (`way=12338359`, unsignalised, 1 lane) — validates 6-exit counting and exit-signal timing cleanly, before upgrading to `way=859` (Kingstanding Circle, 2 lanes) or `way=3382337` (Coven Heath 5-exit signalised).

### New simulator features required (in `core/` and `unity/`)
1. **Arbitrary exit-count & per-exit lane choice (`RoundaboutRule.cs`):** Generalise `GB.RBT.APPROACH_LANE` and `GB.RBT.SIGNAL_APPROACH` beyond fixed 4-arm clock-face assumptions so 5- and 6-exit roundabouts map each exit (`1..N`) to allowed approach lanes via `RoadPack.laneConnections[]` and sign/arrow data rather than assuming exit 2 = straight ahead.
2. **Spiral lane markings & lane-gain/lane-drop (`RoadPack` / `Sim.Core`):** Support circulatory segments where `lanesForward` changes between arms (`lanes=2 -> 3 -> 2`) and outward-spiralling lane dividers guide inner-lane traffic smoothly to exit `N-1`/`N` without an illegal lane change.
3. **Internal circulatory traffic signals (`SignalPlan` + `TownRules.cs`):** Support stop lines *inside* the roundabout ring (at `sigs > 0` nodes) so `GB.TL.RED` / `GB.TL.AMBER` apply at signalised circulatory arms while `GB.RBT.GIVE_WAY_RIGHT` yields to signals when active.
